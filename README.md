# Gatu · Privacidade

Política de Privacidade oficial do Gatu, reprodutor de mídia para LG webOS.

Responsável: Lucas Antonio da Silva · Suporte: gatu.support@gmail.com

## Publicação

Envie os arquivos deste diretório para a raiz do repositório público `gatusupport/privacy`, preservando a pasta `assets`. Em **Settings → Pages**, escolha **Deploy from a branch → main → /(root) → Save**.

URL prevista após a publicação: https://gatusupport.github.io/privacy/

Confirme a URL apresentada pelo GitHub e abra a página sem login antes de utilizá-la na submissão à LG.

## Conteúdo

- `index.html`: página e texto da política.
- `styles.css`: estilos responsivos, navegação e impressão.
- `assets/`: identidade visual original do Gatu.
- `.nojekyll`: publicação direta dos arquivos estáticos.

Sem dependências de build, JavaScript, formulários, cookies próprios ou analytics. O GitHub Pages é o provedor de hospedagem, conforme descrito na política.

Este repositório contém a página pública de privacidade. O código do aplicativo e os materiais de QA da LG ficam no projeto de desenvolvimento.
